# ICPC: рабочая папка

Задачи первого этапа: `A.py`–`O.py` и `A.cpp`–`O.cpp` (15 букв). В каждом файле есть точка входа и быстрый ввод. Пишите решение в `solve()`; выводите ответ через `print` или `cout`.

```sh
python3 A.py < input.txt
./run.sh A.cpp < input.txt
./run.sh A.py < input.txt
./run.sh A.cpp cases/A.toml
./run.sh A.py cases/A.toml
```

`run.sh` компилирует C++17 во временный каталог, поэтому исполняемые файлы не засоряют папку. В файлах задач оставлен только `#include <bits/stdc++.h>`. Локально `run.sh` подставляет совместимый заголовок из `local_include/bits/stdc++.h`; на сервер отправляйте **только файл задачи**, и там подключится настоящий GNU-заголовок. Для ручной локальной компиляции: `g++ -std=c++17 -I local_include A.cpp -o A`. Файл `.clangd` помогает редактору находить этот заголовок. Код нужного алгоритма возьмите из `algorithms/`.

## Несколько кейсов одной командой

Для каждой задачи есть файл `cases/A.toml`–`cases/O.toml`. Раскомментируйте образец и добавьте сколько угодно блоков `[[case]]`:

```toml
[[case]]
name = "обычный пример"
input = '''
2 3
'''
expected = '''
5
'''

[[case]]
name = "посмотреть ответ"
input = '''
10 20
'''
```

Запуск: `./run.sh A.cpp cases/A.toml` или `./run.sh A.py cases/A.toml`. Для C++ программа компилируется **один раз**, затем каждый кейс запускается как отдельный процесс. Если `expected` задан, появится `УСПЕШНО` или `НЕ ПРОШЁЛ`; иначе вы увидите фактический вывод. Проверка сравнивает слова и числа, игнорируя различия в пробелах и переводах строк. При ошибке или превышении времени команда завершается с кодом 1. По умолчанию лимит — 3 секунды на кейс; изменить его можно через `--timeout 10`.

Краткий указатель по алгоритмам, их применению и сложности: [ALGORITHMS.md](ALGORITHMS.md).

Все Python-файлы алгоритмов содержат функции или классы без автоматического чтения ввода. C++-файлы содержат самостоятельные функции или классы без `main`; при переносе в решение копируйте также нужные `#include` из начала файла. Индексы вершин и массивов в заготовках обычно начинаются с нуля. Исключения и формат аргументов указаны рядом с функциями.
